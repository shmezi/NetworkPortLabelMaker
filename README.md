# Network Port Label Generator

## About This Project
Hi, this is not something I developed one bit; unlike most of my projects, this was done purely vibe-coded. I needed a tool to get some work done easier, so I asked Gemini to build it. After an hour of reworking different aspects, this is the result. I am uploading it here for everyone (including myself) as a GitHub page.

You can access and use the live tool directly by going to [port.ezra.network](https://port.ezra.network).

---

## Features

* **Visual Hardware Rack Preview:** See a live visualization of your network hardware row configuration.
* **Category & Color Management:** Create custom categories and assign color codes to them.
* **Flexible Port Spans:** Configure port widths, standard gaps, group spacing, and individual port spans.
* **Smart Print Layouts:** Automatically packs labels efficiently for A4 paper printing, splitting groups or rows cleanly when wrapping.
* **Bilingual Support:** Full support for both English (LTR) and Hebrew (RTL) out of the box.
* **Bulk Data Utilities:** Download CSV templates, upload CSV data files, or quickly generate sequential port runs.
* **Client-Side Storage:** Automatically saves your work locally in your browser so you never lose your configuration.

---

## How to Use

1. Visit the live site at [port.ezra.network](https://port.ezra.network).
2. Configure your dimensions, add your categories and port entries, and hit **Print Label Sheets** when ready!
